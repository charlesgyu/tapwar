# 모두의 힐러 (Everyone's Healer)

> 세로 화면 모바일 RPG. 5인 파티의 **힐러**가 되어 99층 탑을 오른다.
> 귀여운 도트 캐릭터, 탑을 둘러싼 상권 마을, 힐·저주해제·버프 중심의 전투.

## 실행 방법

빌드·서버 없이 순수 HTML/JS/Canvas 로 동작합니다(번들러·모듈 없음, 전역 스크립트만).

```bash
# 1) 파일로 바로 열기 — 서버 없이 file:// 로도 동작
open healer/index.html            # 또는 브라우저 주소창에 파일 경로

# 2) 폰에서 보려면 정적 서버
python3 -m http.server 8080       # 저장소 루트에서 → http://<PC IP>:8080/healer/
```

- 세로 화면 폰 기준(390×844). 데스크톱에서는 개발자 도구의 모바일 모드로 보면 됩니다.
- 저장은 `localStorage['healer.save']`(60초마다·씬 전환·화면 닫기·앱 숨김 때 자동). 저장이 있으면 타이틀(이어하기/새 게임)이 뜹니다.
- `index.html?nointro` 는 프롤로그 연출을 건너뜁니다(테스트용). 콘솔의 `window.__healer` 로 상태(`G()`)·마을(`goTo`, `talkTo`)·던전(`dungeon.teleport`, `dungeon.fs`)에 접근할 수 있습니다.

### 테스트·도구

```bash
node healer/tools/run_tests.js                 # 코어 단위 테스트(151개)
node healer/tools/e2e_app.mjs [outDir]         # 실제 index.html 을 폰 크기 Playwright 로 처음부터 끝까지(아래 표) — 단계별 스크린샷
node healer/tools/sim.js <floor|all> [초]       # 적정 레벨 파티 자동 전투 시뮬레이션(생존율·클리어 시간)
node healer/tools/map_preview.js <floor|all>   # 던전 생성 미리보기
node healer/tools/ui_preview.mjs <screen> <out.png> [paramsJSON] [stateJS]   # 화면 하나 미리보기
node healer/tools/dungeon_shot.mjs <floor> [outPrefix] [level]               # 던전 씬 스크린샷
```

E2E(`e2e_app.mjs`)가 확인하는 흐름: 새 게임 → 프롤로그 건너뛰기 → 마을(화면 탭 이동) → 장로 엘다 대화 → 메인 퀘스트 수락 → 성문 경비 대화 →
모험가 사무소 4명 고용 → 상인(포션·장비 구매) → 가방(벨트 등록·장착) → 신전 스킬 강화 → 은행 입금 → 여관 식사 → 경매장 → 대장간 조합 → 길드 가입 →
성문 → 1층(인트로 건너뛰기) → 자동 탐험 → 무리 전투(힐·데미지 숫자·텔레그래프, fps ≥ 50) → 상자 → 보스(소환 패턴) → 출구 → 결과 화면 → 마을 →
퀘스트 완료 → 저장 → 새로고침 → 이어하기(같은 상태) → 2~10층 입장(6층 힐러 저격 광역기 확인). 콘솔 오류 0 이어야 통과합니다.

## 게임 기획 요약

### 핵심 루프
탑(1~99층) 진입 → 탱커가 어그로, 딜러가 사냥, **나는 힐로 파티를 살린다** → 보상(재화·아이템·경험치) → 장비 업그레이드/레벨업/스킬 강화 → 더 높은 층. 최종 목표는 99층 클리어로 세상에 평화 가져오기(길드 고정 파티가 핵심).

### 힐러 스킬
- **단일힐**: 기본힐(느린 캐스팅) / 빠른힐(캐스팅 2배 빠름, 마나 1.5배) / 즉시힐(캐스팅 없음, 마나 2배)
- **광역힐**: 무작위 2명 / 무작위 3명 / 바닥힐(마법진 위 아군 초당 회복)
- **필살기**: 파티 전원 HP 즉시 80% 회복 (쿨타임 5분)
- **부활**
- **저주 해제**: 도트데미지, 방어력↓, 공격력↓, 공격속도↓, 이동속도↓, 받는 힐 50%↓, 이동불가
- **버프**: 공격력↑, 회피↑, 방어력↑, 이동속도↑, 공격속도↑, 마나소비↓
- 언데드에게는 공격 마법 가능. 힐할수록 마나가 줄어 **마나 관리** 필수.

### 전투 중 주의
- 힐러도 몬스터 광역기에 맞는다. 10층까지는 탱커 어그로로 안전, 이후로는 피해야 함.
- **공격 영역**: 바닥에 영역 표시 → 3~5초 준비(색이 차오름) → 공격
- **장판**: 빨간 원형 마법진 → 3~5초 후 약 5초간 초당 도트 데미지

### 몬스터
WoW 호드/판타지 계열: 오크, 트롤, 나가, 늑대인간, 고블린, 드래곤, 세이렌, 셰피, 골렘 등.

### 아이템
- **장비**: 장신구(목걸이·반지·귀걸이), 손(양손지팡이 | 한손지팡이+책), 사제옷, 장화, 장갑, 모자, 벨트(등급별 소모품 1~4칸 자동 사용), 가방(인벤토리)
- **등급**: 일반 / 고급 / 레어 / 전설. 레어부터 추가 효과(초당 마나회복, 캐스팅 속도↓, 마나소비↓, 이동속도↑ …)
- **세트**(옷·장화·장갑·모자·벨트): 2/3/4/5개 착용 효과. 확률형 보조(10% 마나 무소비, 10% 기본힐 즉시시전 …)
- 방어구 재질: 판금(전사·탱커), 가죽(사냥꾼·도적), 사슬(마검사), 천(마법사·사제). 드랍은 재질을 가리지 않음. 퀘스트 보상은 항상 사제용.
- 소모성/소지성 아이템 별도.

### 퀘스트
메인 스토리 / 마을 의뢰 / 일일(하루 3회, 재화) / 히든(던전에서 획득, 좋은 장비)

### 마을 NPC·시설
| 시설 | 역할 |
| :--- | :--- |
| 모험가 사무소 | 파티 찾기·만들기·영입, 퀘스트 수주 |
| 길드 | 가입/창설, 고정 파티 구성(핵심) |
| 대장간 | 수리·분해·조합 |
| 여관 | 음식·숙박으로 피로 해소(피로 누적 시 스탯 % 감소) |
| 상인 | 포션·재료 판매, 잡템 매입 |
| 경매장 | 현실 1시간 주기 리셋, 내 장비 판매, 리셋권(유료/퀘스트) |
| 은행 | 아이템·재화 보관(가방 칸 제한 때문에 필수) |
| 각인사 | 몸에 주문 각인(스탯, 확률형 특수 능력) |
| 신전 | 사제 스킬 레벨업(재화 사용) |
| 탑 입구 | 던전(탑) 진입 |

### 파티·직업·역할
- 파티 5인, 구성 자유(힐러 5명도 가능)
- 역할: 탱커 / 근접딜러 / 원거리딜러 / 힐러
- 직업: 전사·무투가(탱커/근딜), 마법사·사냥꾼(원딜), 도적·마검사(근딜), 사제(힐러)

### 스탯·레벨
- 힘(근접 공격) / 방어력 / 민첩(이동·공격속도) / 지구력(피로 저항) / 지능(마법공격·힐량) / 체력(HP)
- 레벨업마다 스탯 포인트 5, 레벨로 스킬 개방, 만렙 40
